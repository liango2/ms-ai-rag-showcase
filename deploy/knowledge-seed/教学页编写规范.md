# AI 教学页编写规范（写给以后写教学页的自己 / AI 的提醒）

> **一句话：** 每篇教学页必须**说人话 + 真实实现代码/伪代码 + 一个能跳到 gitee 当时提交代码比对（commit diff）的链接**。别只讲概念，要让学习者点进代码看到"这就是刚才那个现象的实现"。

## 为什么要有这条

- 光讲现象（200/429、熔断红绿灯）学习者懂了现象，但一关页面就忘、也不会改。
- 把**核心实现代码**贴进页面 + 挂一个 **gitee 提交比对链接**，学习者能：
  1. 对照页面现象读代码，看懂"为什么"；
  2. 点进 gitee 看当时是**哪次提交、改了哪些文件**（真实变更，不是抄的）。
- 也防止我自己（AI）以后偷懒：以为讲讲流程就算写完教学页了。

## 每篇教学页必带的 6 件套（缺一不可）

| 序号 | 要素 | 说明 |
|---|---|---|
| 1 | **说人话 + 类比** | 用生活化类比讲原理（景区门口=限流、防雪崩=熔断…），不堆术语 |
| 2 | **豆沙绿护眼配色** | 页面背景用护眼豆沙绿（#eef5e9 / #f4f8f1），和其它教学页保持一致 |
| 3 | **自测按钮 / 接口自测带 token** | 页面内直接能登录拿 JWT、点按钮调网关看返回（不是只给 curl） |
| 4 | **实现代码（伪代码 + 核心代码 + 参数表）** | 至少贴出该功能的核心配置/核心方法，配合参数含义表 |
| 5 | **gitee 提交比对链接** | 链接指向该功能引入/定型的那次提交的 diff |
| 6 | **状态码加"人话"含义** | 200=放行、429=限流、500=下游故障、503=熔断短路…别只给数字 |

## 怎么贴"实现代码"区块（直接照抄 07/08/09/10 的结构）

在页面末尾（生产注意事项 callout 之后、`</div>` 主容器结束前）加一个 `.card`：

```
<div class="card">
  <h2><span class="stepno">N</span> 实现代码 · <功能名></h2>
  <div class="tip">伪代码 · 说人话核心逻辑</div>
  <div class="params"><table>参数含义</table></div>
  <pre>核心代码（转义 &gt; &lt; &amp;，等宽/护眼底色）</pre>
  <div>
    这份代码是那次提交引入的：
    <a href="https://gitee.com/540625404/ms-demo/commit/<hash>">
      ↗ 查看 gitee 提交代码比对（<hash> · <一句话说明>）
    </a>
  </div>
</div>
```

样式直接复用现成内联样式（见 07 的步骤7 / 08 的步骤8）：
- `pre` 底色 `#f4f8f1`、边框 `#d7e8cf`、圆角 8px、等宽字体、`overflow:auto`
- gitee 链接：绿色边框圆角小按钮（白底 + `#4c8f4a` 描边/文字）

## 怎么找对应的 gitee 提交 hash

在本地仓库：

```bash
cd ms-demo
git log --oneline --all | grep -iE "<功能关键词>"     # 如 限流|超时|熔断|cors
git log --oneline -- <实现文件>                         # 看某个文件被哪几次提交改过
```

原则：
- **引入该功能**的提交 → 用 `fc14e84`（网关四件套那次）这类"第一次把功能加进来"的提交，diff 最全；
- **定型/修复关键行为**的提交 → 用像 `c80fd15`（去 fallbackUri 定熔断行为）、`80d4fd7`（CORS 生产不装配）这种"把行为改对"的提交，更贴合教学主题。

链接统一格式：`https://gitee.com/540625404/ms-demo/commit/<hash>`（gitee commit 页自带文件 diff）。

## 部署流程（纯静态，不打 jar、不重启网关）

```bash
# 1. 自检（必跑，禁用手动截图/其它工具）
python3 <html_skill>/scripts/shot.py <教学页.html>    # 看 consoleErrors + Read 截图

# 2. 拷到云机 + sudo 放到 nginx 静态目录
scp <教学页.html> msdemo:/home/admin/upload/learn/ms-demo/
ssh msdemo "sudo cp -f /home/admin/upload/learn/ms-demo/<教学页.html> /usr/share/nginx/html/learn/ms-demo/"

# 3. 公网验证（注意中文文件名要 URL 编码）
curl "http://101.43.45.217/learn/ms-demo/<url编码的文件名>.html" | grep -oE '实现代码|commit/[0-9a-f]+'

# 4. 提交代码库
cd ms-demo && git add 学习页 && git commit && git push
```
